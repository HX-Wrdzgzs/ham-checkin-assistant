## 1. 设计目标与边界

- **[PROPOSED]** 以 Windows 桌面现场工具为目标：简洁、表格 / 列表优先、键盘优先、主输入先于装饰；参考 Windows Fluent 的清晰层级、焦点和系统行为，不复制任何产品页面。
- **[PROPOSED]** 单一品牌强调色；成功、警告、错误色只表达对应语义。少用容器分组，不用网页式 Hero、大统计卡、装饰卡片、强渐变、玻璃、发光、厚边框、巨大圆角 / 重阴影或 Emoji 代替图标。
- **[USER_APPROVED]** 三种主题（FollowSystem / Light / Dark）是已确定要求，新安装默认 FollowSystem；浅色 / 深色仍可由用户选择。精确色值和组件细节另按实现时对比度与平台验收，不视为已通过。
- **[CURRENT STATIC FACT]** 当前实现固定浅色；固定浅色不是三主题或全软件 UI 合同完成的证据。
- **[NOT_VERIFIED]** 本规范、历史截图、静态 XAML 和审计机均不证明 Win10 / Win11、DPI、真实 IME、UI Automation、读屏或高对比通过。

## 3. 字体、密度、网格与窗口尺寸

- **[PROPOSED] 字体：** 首选 Segoe UI；中文回退使用 Windows 中文 UI 字体（例如 Microsoft YaHei UI），不依赖可变字体安装。正文 13–14 pt；表格 / 次级信息不低于 12 pt；输入 18–20 pt；标题建议 22 / 18 pt 两级。最终字号需实机字体缩放测试。
- **[USER_APPROVED] 主界面字重：** 用户于 2026-11-21 要求整个界面加粗；主窗口根节点继承 `FontWeight="SemiBold"`（`MainWindow.xaml:14`），现有显式 SemiBold/Bold 保留。本机 Microsoft YaHei UI 仅有 Regular/Bold/Light，`Medium` 无法形成可见加粗，故不使用 Medium；字体家族与字号不因此改变。真实 DPI / 字体缩放矩阵仍待验。
- **[PROPOSED] 网格：** 8 px 基础节奏；主区外边距 16 px；区块间距 8 / 12 px；表格行高 36–40 px、表头 36 px；按钮与输入触控目标至少 36 px。紧凑 / 舒适密度切换不在本候选默认范围，待真实需求确认。
- **[PROPOSED] 对齐：** 序号、功率、时间等数字列对齐并尽可能等宽；中英数、呼号混排可读；长文本可以视觉省略，但详情和焦点路径可读全文，不静默丢弃原文。
- **[PROPOSED] 控件：** 保留标准窗口标题栏与按钮；小圆角 4–6 px、细边框、无重阴影 / 玻璃 / 渐变；使用可缩放单色矢量或系统 glyph，并保留可见文字。
- **[CURRENT STATIC FACT]** 当前主窗标准窗口最低尺寸 800×600，QuickWindow 最低尺寸 420×190；**[PROPOSED]** 候选布局保持可操作基线，但尺寸需在 DPI / 混合屏实测，不以固定像素替代 WPF 缩放。

## 5. 交互状态（11 态）与组件适用性

**[PROPOSED]** 有意义的状态至少用文本、形状、图标、语义色中的两种表达，并暴露给 UI Automation / 读屏。Loading 不隐藏当前草稿或选中行；Error 给出可理解原因和真实恢复动作；Offline 不等于本地签到不可用。不是每个控件都机械拥有 11 态。

| 状态 | 候选行为 |
| --- | --- |
| Default | 输入、按钮、表格、导航保持稳定对比；默认页突出输入与提交，不突出装饰数字 |
| Hover | 仅加强边界 / 底色，不触发动作或改变布局；触屏不依赖悬停 |
| Pressed | 短暂底色 / 边框反馈；不缩放、不延迟命令 |
| Focus | 高对比焦点框与明确顺序；输入、候选、表格、导航可键盘到达 |
| Selected | 导航、记录、候选与 Focus 分开表达；切换场次不误保留旧选中 |
| Disabled | 写操作仅在确需禁用时降对比但仍可读；显示原因，不锁死整个窗口 |
| Loading | 标明所属迁移、目录、MIIT、导出、更新或媒体收尾任务及能否取消；草稿仍可用 |
| Success | 仅在事务 / 导出 / 录制收尾实际成功后显示文字 + 图形反馈；提示消退后仍可查状态 |
| Error | 区分输入、数据库、导出、媒体、更新错误；保留草稿 / 原文件，提供真实恢复动作 |
| Empty | 无记录、无搜索结果、无候选、无地点包使用不同说明和下一步；空列表不表示成功 |
| Offline | MIIT / 更新 / QTH 远端标为离线或未配置；本地资料、已存在记录和本地提交仍可用 |

| 组件族 | 适用状态 |
| --- | --- |
| 主导航 | Default、Hover、Pressed、Focus、Selected、Disabled；Loading / Success / Error / Empty / Offline 属页面内容，不套在导航按钮上 |
| 输入与候选 | 按实际控件使用全部交互态；Loading 只用于解析 / 建议等待；候选 Empty 与 Offline 区分；IME 组合时 Enter 不提交 |
| 记录表 / 详情 | 按内容提供 Default、Focus、Selected、Disabled、Loading、Success、Error、Empty、Offline；仅可操作行 / 动作具有 Hover / Pressed |
| 提交 / 场次 / 导出命令 | 按钮使用 Default、Hover、Pressed、Focus、Disabled、Loading；Success / Error 由结果消息表达；Empty / Offline 是伴随内容 |
| MIIT / 更新作业 | Default、Focus、Disabled、Loading、Success、Error、Empty、Offline；可操作按钮才有 Hover / Pressed；离线、未配置、失败分开 |
| 录屏 / 麦克风 | 交互态按动作适用；断设备用 Error / Offline 文案；Paused / Finalizing 是业务状态，不以动画代替 |
| 对话框 / 设置 | 按字段和任务应用相关状态；明确键盘 Esc、取消、关闭、保存目标，不丢数据 |

## 6. 动画和降级

**[PROPOSED]** 动画仅作短反馈，不把解析、网络、SQLite 事务、保存或安全确认放在动画里。

| 反馈 | 候选时长 | 约束 |
| --- | --- | --- |
| Hover | 80–120 ms | 仅颜色 / 描边过渡 |
| Button | 60–120 ms | 不缩放、不延后命令 |
| Menu | 100–180 ms | 系统减少动画时立即显示 |
| Dialog | 150–220 ms | 不阻塞键盘焦点或输入，不做弹簧效果 |
| Page | 150–250 ms | 页面内容先可交互；网络 / 解析 / 事务不在动画内 |
| 关闭动画 | 0 ms | Windows 显示动画关闭或应用动画关闭时直接切换；不绕过安全确认 |

- **[CURRENT STATIC FACT 2026-11-22]** 主页面切换与关于、字段编辑、快速小窗、场次编辑、场次选择入口已按本表实现：页面 180 ms、窗口 160 ms 淡入+位移；统一由 `WindowMotion` 处理，尊重 `SystemParameters.ClientAreaAnimation` 与“过渡动画”开关。Hover / Button / Menu 的颜色过渡仍未实现；真实 DPI、多屏、IME 与读屏矩阵仍为 NOT_VERIFIED。
