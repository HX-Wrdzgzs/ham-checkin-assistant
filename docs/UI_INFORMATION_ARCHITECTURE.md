## 3. 数据关系、业务边界与用户流程

### 3.1 关系与数据来源

- **[CURRENT STATIC FACT]** 场次与签到记录保存于本地 SQLite；简化关系为一个 Session 对应零条或多条 Checkin。记录关联场次，并保留原始文本、已确认字段和未识别内容。具体 ended 写入约束、并发编辑及事务不变量仍是独立验收事项。
- **[CURRENT STATIC FACT]** 解析器读取内存中的 CatalogSnapshot；目录装载与 MIIT / QTH 网络任务不得进入点名热路径。历史 SQLite 是只读兼容来源，源库须保留。
- **[CURRENT STATIC FACT]** Excel 是可选的导入、导出和显式同步边界，不是 SQLite 主库或提交所需依赖。场次路径绑定不等于正在同步，导出必须固定当前选定场次。
- **[CURRENT STATIC FACT]** 录屏、麦克风、更新检查和目录同步均为独立任务边界；麦克风需用户显式启用。远端 MIIT、QTH 地点包、GitHub Release 和稳定版本状态均须各自核实。
- **[PROPOSED]** 页面只展示可证实的本地 / 网络任务状态，不增加数据字段、角色、后台队列、自动学习或第二套工作流。
- **[CURRENT STATIC FACT]** 本 IA 仅呈现当前可核实的数据关系；旧→Native逐表/字段/来源/审计映射与LegacyProfileReader入口定位未闭合，分别留在LB-T02/T08并作为PLAN-P3-DATA前置。本提案不将缺项补成未经核实的数据契约。

### 3.2 快速点名到场次结束

1. **[CURRENT STATIC FACT]** 操作员输入草稿；Native 解析器结合内存 CatalogSnapshot 提供预览、候选和未识别文本。预览不得回写或覆盖后续草稿。
2. **[CURRENT STATIC FACT]** 操作员明确按 Enter 才提交；NativeStore 执行短 SQLite 事务。解析、目录、Excel、网络或媒体任务不得阻塞输入热路径。
3. **[PROPOSED]** 成功只在事务成功后以文字和图形反馈，并把新记录加到当前场次列表；失败保留草稿及未知内容，错误明确并提供真实恢复动作。
4. **[CURRENT STATIC FACT]** 操作员可浏览本场记录并显式修改允许字段；字段候选由用户选择，不能悄悄替换已确认字段。
5. **[PROPOSED]** 操作员可选固定当前场次导出 / 同步；导出结果与记录事务分别显示，失败不倒置已提交 SQLite 记录。
6. **[PROPOSED]** 操作员显式结束场次；结束后只读状态覆盖各页面，浏览 / 导出与写入禁用原因清晰可见。

### 3.3 非热路径旁路

- **[CURRENT STATIC FACT]** 本地 / 兼容资料装载 → CatalogSnapshot → 输入解析。MIIT 同步和地点包各自显示作业状态；离线不阻止已装载本地资料和点名。
- **[CURRENT STATIC FACT]** Excel 任务在用户明确启动后运行；更新在设置 / 关于中手动检查；媒体在录屏页面显式操作。任何任务状态不得伪装成另一项任务的成功。
- **[NOT_VERIFIED]** MIIT 全量来源、远端地点详细包、更新远端状态、取消 / 续传恢复、备份恢复和跨设备行为仍需独立验证。
