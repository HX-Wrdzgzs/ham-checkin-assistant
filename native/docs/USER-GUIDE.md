# HAM 点名助手 Native 1.0.17 操作指南

## 1. 启动与场次

双击 `HAM点名助手.exe`。程序启动时不连接 Excel，先进入可录入界面；数据默认保存在：

```text
%LOCALAPPDATA%\HAM点名助手\
```

顶部场次栏可以新建、选择、编辑和结束场次。正常启动优先打开最早的可写活动场次；已结束场次默认只读。

已结束场次会同时禁用快速输入、快捷小窗提交和本场记录字段编辑；需要明确点击“结束/重开”后才恢复写入，避免在只读历史场次中误录。

## 2. 快速点名

在“快速点名”输入框中输入一整行，例如：

```text
BA4AAA NJXW PD780 4.2M 5W
```

预览只显示规范化结果，不会把原文改写回输入框。按 Enter 提交；成功后输入框清空并重新聚焦，SQLite 先保存，Excel 后台导出。

如果提交期间继续输入下一条，上一条保存完成后不会清空新草稿。主窗口和快速小窗共享场次与提交服务，但当前有焦点的输入框保留自己的光标、选区和撤销栈。

快捷小窗默认约 `560×280`，最小约 `420×190`。窗口缩到最小高度时会自动收起最近记录，场次、输入框、当前解析、提交按钮和状态栏仍保留；恢复到普通高度后最近记录自动显示。

常见结果：

- `njxw` → `江苏省南京市玄武区`
- `pd780` → `海能达 PD-780`
- `r6` → `摩托罗拉 R6`
- `4.2m` → `4.2米玻璃钢`
- `5w` → `5W`

没有可靠证据的设备型号会保留原文，不会自动猜品牌。例如当前 `pd660pro` 仍保留为 `pd660pro`；在设备字段编辑器中可以看到本地资料快照提供的相近型号候选，但必须由你明确选择后才会替换。

如果省份明确但现场城市缩写未收录，例如 `山东qcd`，软件会保留为 QTH 原文并标记为待修正，不会擅自猜成青岛或其他城市。

## 3. 修改单条记录

进入“本场记录”：

1. 单击只选择单元格。
2. 双击，或选中后按 Enter/F2，打开字段编辑器。
3. QTH、设备、天线、功率等编辑器只修改当前字段，不会重新解析并覆盖其他字段。
4. 编辑器中可以复制原始录入、复制全部未识别内容、复制单个片段，或明确点击片段填入当前字段。
5. 只有明确采用的未识别片段会被移除；取消保存不会改变记录。

## 4. Excel 导出

点击“导出 Excel”。新文件固定包含九列：

```text
序号、时间、呼号、QTH、设备、天线、功率、信号、来源
```

文件顶部包含中继名称、场次名称、场次日期和主控呼号；新文件不包含“未识别”列。Excel 被占用或导出失败时，SQLite 中已经保存的点名记录不会被删除。

## 5. 录屏与麦克风（高风险操作）

进入“录屏 / 麦克风”前先确认输出路径和麦克风。录屏页应显示：`HAM 点名助手窗口 · 宽×高 · 仅录制软件窗口`。本功能只采集 HAM 点名助手窗口客户区，不提供显示器/整屏目标，也不会在采集失败时退回桌面截图。

推荐流程：

1. 选择麦克风，点击“测试麦克风”，确认电平有变化。
2. 输出文件必须是 `.mp4`；编码为 H.264 视频，启用麦克风时包含 AAC 音频。
3. 点击“开始录制 MP4”。录制期间不要把软件窗口关闭；可以先用 5～10 秒短录测试。
4. 点击“停止并保存”，等待状态变成“录屏已保存”，再用系统播放器打开文件。
5. 如果目标文件已经存在，软件会拒绝覆盖；请选择新文件名。
6. 如果窗口采集、编码或麦克风失败，状态必须显示失败，不要把失败文件当作成品。失败产生的临时 `.partial.mp4` 会清理；失败未清理时不要手工改名使用。
7. 窗口关闭和停止按钮同时触发时只执行一次收尾；不要在“正在收尾录屏文件”时重复开始新录屏。

现场安全检查：

- 先录制 5 秒，打开其他窗口后停止，用播放器确认成品中没有其他窗口。
- 确认已有 MP4 没有被覆盖。
- 确认麦克风电平、视频画面和音频都正常后，再开始长录。
- 录屏完成后检查文件大小和能否打开；不要只看软件状态文字。

## 6. 资料库和更新

资料库、地点包、工信部同步和更新检查都在后台运行，不进入快速输入热路径。地点包树先显示全国省/市行政区节点，再合并本地已安装数量；详细道路/地标包源尚未配置时，省市会明确显示“未下载”，不会伪装成已下载。更新渠道保持现有 GitHub Release、`main/updates/latest.json` 和 SHA-256 校验约定。1.0.17-r24 当前是本地候选版，正式上传和远程清单切换需要单独发布操作。
