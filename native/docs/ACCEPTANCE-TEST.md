## 用户现场验收顺序

1. 优先从 Downloads 打开自包含包 `HAM点名助手-HX-HAM-1.0.19-r28-候选\HAM点名助手.exe`；本轮候选包已包含 .NET 10 Desktop 运行时，不需要另装运行时或保留旁置 DLL。
2. 确认数据路径显示在 `%LOCALAPPDATA%\HAM点名助手\data`，而不是 EXE 当前目录；确认启动没有打开 Excel。
3. 确认默认进入最早的 active 场次；没有可写场次时创建当天的第 1 场。
4. 在输入框输入并提交：

   ```text
   BA4AAA NJXW PD780 4.2M 5W
   ```

   应看到：`江苏省南京市玄武区`、`海能达 PD-780`、`4.2米玻璃钢`、`5W`，未识别为空。

5. 输入 `BA4AAA R6 Y H NJXW`，确认设备是 `摩托罗拉 R6`，而不是只写 `R6`。
6. 输入一个未知片段，例如 `BA4AAA XZ-991 5W MYSTERY`，确认呼号和已识别字段仍可保存，`MYSTERY` 留在待修正计数中。
7. 打开“本场记录”，双击该行 QTH：
   - 编辑器只标记“当前修改 QTH”；
   - 可以复制全部/单个未识别片段；
   - 输入 `njgl中山路169号`，预览应为 `江苏省南京市鼓楼区中山路169号`；
   - 保存后设备、天线、功率不变，只消费明确填入的片段。
8. 双击设备输入 `pd780`，确认保存为 `海能达 PD-780`；双击天线输入 `4.2m`，确认保存为 `4.2米玻璃钢`。
9. 打开“设置”，修改一个软件内快捷键，确认立即生效；修改 `Ctrl+Space` 时若系统占用，确认旧全局热键会保留。
10. 打开“资料库”，确认工信部按钮包括首次下载、检查更新、完整重下、继续和取消；同步期间继续输入一条记录，确认窗口不等待网络。
11. 查看地点包的省/市树。树应显示全国省级节点；已安装的 `qth_places.db`/`qth_admin.db` 合并显示数量，其余省市显示“未下载”。远程详细道路/地标包源尚未配置，因此按钮会明确提示，不应把此项记为联网下载 PASS。
12. 点击“导出 Excel”，确认新文件：
    - 顶部有场次名称、场次日期、主控呼号和中继名称；
    - 表头只有序号、时间、呼号、QTH、设备、天线、功率、信号、来源九列；
    - 没有“未识别”列；
    - Excel 未安装或文件不可写时，SQLite 记录仍然保留。
13. 打开“录屏 / 麦克风”，按黑盒流程确认：
    - 录制目标只显示 HAM 点名助手软件窗口客户区，没有显示器/整屏选项；
    - 输出扩展名固定为 `.mp4`，开始前选择麦克风并点击“测试麦克风”；
    - 录制时打开其他窗口，成品中不应出现其他窗口；
    - 正常停止后用系统播放器打开 MP4；
    - 指定一个已有 MP4 再开始，软件必须拒绝覆盖并保持原文件不变；
    - 录制窗口被关闭或采集失败时，软件不得提示“已保存”，也不得留下可被误认为成品的临时文件。
14. 点击“结束/重开”，确认结束后不能提交，重新打开后可以继续；选择已结束场次时不会自动改变当前场次以外的数据。
15. 重启程序，确认快捷方式位置、EXE 位置和当前文件夹都不会改变 `%LOCALAPPDATA%` 数据路径。

16. 选择一场已结束场次，确认快速输入、快捷小窗提交和本场记录字段编辑均为只读；点击“结束/重开”重新打开后，才允许继续录入和编辑。

## 现场验收记录格式

每一步记录 `PASS / FAIL / NOT_RUN / NOT_VERIFIED / BLOCKED`，并附：

- 软件版本和 EXE SHA-256；
- 截图；
- 发生失败时的日志或错误文本；
- 导出的新 Excel 文件；
- 是否在资料同步期间继续完成输入。

未完成用户现场验收前，不把候选包标成正式稳定发布；Native 1.0.19 候选仍沿用既有更新协议，远程清单由正式 Release 工作流在发布成功后切换。
