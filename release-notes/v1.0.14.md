# HAM 点名助手 Native 1.0.14

## 本次更新

- 基于三份实际点名表的 129 条记录回放，修复现场设备和天线识别边界。
- `GM338` 现在保留为 `摩托罗拉 GM338`，不再把品牌遗留到未识别。
- `泉盛 TK11` 不再被模糊候选误判为 `泉盛 UV-K1`。
- `即时通 D900` 不再被短别名规则误判为 `即时通 D9000`。
- 增加 `KT-118`、`AR-152`、`威诺-N76`、`威派克斯 2108`、`1.2米玻璃钢` 等现场写法。
- 收紧设备模糊搜索，未知型号不会因为包含 `K1` 等短别名就自动套用错误标准名。
- 保留全国省、市、区县缩写和地点规范化能力；实际三份表格重放 129 / 129 行无剩余差异。

- 版本仍使用原有 GitHub Release、稳定清单和 SHA-256 更新渠道；本地未宣称已上传 GitHub。
- 中文输入法长时间现场操作、用户桌面 Excel 提示和长时间录屏仍需在用户机器上验收。
