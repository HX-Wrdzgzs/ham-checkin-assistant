# HAM 点名助手 Native 1.0.1

本版本是 Windows 原生版的界面清理与稳定性补丁版，继续使用现有 GitHub Release、稳定更新清单和 SHA-256 校验渠道。

## 更新内容

- 快速点名启动后输入框保持为空，删除示例输入、历史建议条和“套用所选”按钮，避免陈旧内容干扰现场录入。
- 删除快速解析、录屏与设置页面中不参与操作的说明性小字，让页面只保留实际控件和状态。
- 移除没有对应界面入口的“接受当前建议 / Tab”快捷键，避免显示与实际行为不一致。
- 保留快速录入、QTH/设备/天线/功率解析、本场记录、字段编辑、快速小窗和后台任务功能。
- 设置页和关于页新增“赞助开发”入口；赞助完全自愿，不影响软件功能、数据或更新权限。
- 修复重复启动实例退出时释放未拥有 Mutex 可能导致的异常。
- 版本号统一更新为 `1.0.1`，继续使用 C# / .NET 10 / WPF / SQLite 和自包含 `win-x64` 发布。

## 更新与安全

- 发布资产包含 `HAM.exe`、兼容旧客户端的中文文件名映射资产和 `SHA256SUMS.txt`。
- 更新清单会在 Release 工作流构建、发布和校验成功后同步到 `main/updates/latest.json`。
- 快速录入仍不在启动或录入热路径中连接 Excel；现场数据先保存到 SQLite。
