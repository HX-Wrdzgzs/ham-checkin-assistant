# HAM 点名助手 Native 1.0.16

## 本版更新

- 修复窄窗口顶部场次操作区布局：窗口较窄时自动换行到场次标题下方，避免按钮被挤出客户区或无法点击。
- 收敛页面切换与成功提示动画，启动时不再提前播放页面动画，现场录入更稳定。
- 设置页显示每次启动都会后台检查更新；联网失败只更新状态，不阻塞快速点名。
- 继续保留快捷输入和快速小窗的前部、中部、尾部编辑保护；解析结果只显示预览，不回写用户原文。

## 版本与渠道

- Native 版本：`1.0.16`
- 目标：Windows 10 22H2 / Windows 11，x64，自包含 .NET 10 WPF 单文件候选包。
- 更新渠道保持现有 GitHub 仓库、稳定清单、测试标签和 SHA-256 校验约定不变。
- 本文件描述本地候选版变更；在真实 GitHub Release 资产上传并完成现场验收前，不把候选版写入稳定更新清单。
