# HAM 点名助手 Native 1.0.17

## 本版更新

- 修复地点解析服务将不完整呼号 `BH8` 误当作“广西壮族自治区北海市”的边界问题；保护同时覆盖字段解析、建议查询和未来直接调用地点目录的路径。
- 修复输入法/Unicode 文本事件先到而组合结束通知缺失时解析卡不刷新的问题；解析只更新预览，不回写当前输入框。
- 修复 `--data-root` 发布黑盒没有隔离资料库的问题；发布 EXE 现在使用隔离目录的地点/设备快照，`BFUV5R` 实际显示为 `宝峰 UV-5R`。
- 为主窗口当前解析区增加稳定的自动化标识，发布包黑盒测试现在会直接读取真实 WPF 控件中的呼号、QTH、设备、天线、功率和待处理原文，而不是只检查输入框文字。
- 继续回归视频中出现的 `BA4SCR BFUV36 扬州邗江 7900`、`BA4VNN JSYCXS BFUV5R YZ 高`、`BH8`，以及前部/中部/尾部编辑不覆盖后缀的快速小窗场景。

## 版本与渠道

- Native 版本：`1.0.17`
- 目标：Windows 10 22H2 / Windows 11，x64，自包含 .NET 10 WPF 单文件候选包。
- 更新渠道继续使用现有 GitHub 仓库、稳定清单、测试标签和 SHA-256 校验约定。
- 本文件描述本地候选版；远程稳定清单只有在候选包和现场验收完成后才应切换。
