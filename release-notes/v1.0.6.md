# HAM 点名助手 Native 1.0.6

## 本版重点

- 修复主窗口和快捷小窗修改输入前部/中部时后半段消失的问题。
- 输入法组合期间不再让旧解析快照写回输入框；解析结果只做预览。
- 增加常用跨省行政缩写，支持 `shxh`、`zjhz`、`江苏张家港` 等写法。
- 内置全国 2,521 条省、市、区县行政区快照；按省份生成城市短码，启动早期也可识别 `hncs`、`sdwh`、`shbs` 等写法。
- 支持 `pd780南通` 这类设备型号与 QTH 粘连输入，同时阻止 `bh8`、`sgm507` 被误识别为地点。
- 删除逐字解析动画，保留短促页面切换和提交反馈动画。
- 窄窗口侧边栏和场次按钮布局改为自适应。
- 程序进入可录入状态后后台检查 GitHub Release；网络失败不阻塞快速点名。

## 验证范围

- .NET 10.0.401 Release 构建。
- 输入草稿修订、IME 元数据、解析金标准和 WPF 输入控件回归测试。
- Microsoft Pinyin 实体输入法和 Microsoft Excel 兼容性仍需在用户现场环境完成最终人工验收。
