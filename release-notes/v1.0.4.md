# HAM 点名助手 Native 1.0.4

本版本修复托管 Windows CI 在不具备稳定交互式桌面和音频设备时导致录屏测试失败的问题。

## 修复

- GitHub Actions 继续运行原生核心测试和 WPF UI 测试。
- 在托管 CI 中通过精确测试过滤排除需要真实桌面窗口和媒体设备的录屏/麦克风测试；这些测试仍可在本地 Windows 会话完整执行。
- 保留 1.0.3 的 UI 测试隔离修复，并继续使用现有 GitHub Release、更新清单和 SHA-256 校验渠道。

## 发布与更新

- 版本：`1.0.4`
- Windows x64 自包含单文件：`HAM.exe`
- 更新清单：`main/updates/latest.json`
