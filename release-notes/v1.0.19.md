# HAM 点名助手 Native 1.0.19

这是 1.0.19-r29 本地候选版的更新说明。正式稳定 Release 和 `main/updates/latest.json` 在现场验收完成前保持不变。

## 修复

- 修复主窗口和快捷小窗在已有完整输入时修改前部/中部内容，后半段被覆盖或消失的问题。
- 解析预览只展示规范化结果，不再把设备、QTH、天线或功率写回用户正在编辑的原文。
- 修复后台解析结果晚到时覆盖新输入的风险；旧修订结果会被丢弃。
- 修复带省码的全国行政缩写拆分边界：已知完整省市优先，未知尾缀保留在待修正内容中；呼号和带数字设备型号不再误判为地点。
- 保留视频现场样例：`7900`、`jsycxs`、`bh8`、`山东qcd`、`广东省汕头市m507` 均有回归测试。
- 录屏改为只抓取 HAM 点名助手窗口客户区，不回退为桌面/显示器截图；默认关闭麦克风，输出路径统一为 MP4。
- 新增录屏安全黑盒：即使有其他窗口覆盖目标窗口，采集帧仍必须来自 HAM 点名助手，不允许回退到桌面画面；发布版主窗口/快捷小窗各执行 25 轮前、中、尾部编辑压力回归。
- 更新关于页、版本号、更新说明和开发者信息：开发者为 `BA4THG（HX-Wrdzgzs）`。

## 新增与改进

- 启动后自动在后台检查更新，联网失败不会阻塞快速录入。
- 资料库、录屏页和关于页的 AutomationId、状态文案和按钮布局补齐，方便黑盒回归和键盘操作。
- 发布版黑盒已实际点击开始/停止录屏，隔离目录生成并检查 MP4 的 `ftyp`、`moov`、`mdat` 容器标记。
- 继续保持现有 GitHub 仓库、稳定清单、测试标签和 SHA-256 校验渠道，不引入新的更新地址。
