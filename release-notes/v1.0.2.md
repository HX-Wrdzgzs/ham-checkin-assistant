# HAM 点名助手 Native 1.0.2

本版本用于重新发布 Windows 原生版稳定改动，版本号、关于页、设置页、文件版本和程序集版本统一更新为 `1.0.2`。

## 更新内容

- 快速点名启动后输入框保持为空，删除示例输入、历史建议条和“套用所选”按钮。
- 删除快速解析、录屏与设置页面中不参与操作的说明性小字，让页面只保留实际控件和状态。
- 移除没有对应界面入口的“接受当前建议 / Tab”快捷键，避免显示与实际行为不一致。
- 设置页和关于页提供“赞助开发”入口；赞助完全自愿，不影响软件功能、数据或更新权限。
- 修复重复启动实例退出时释放未拥有 Mutex 可能导致的异常。
- 继续使用 C# / .NET 10 / WPF / SQLite、自包含 `win-x64` 发布和现有 SHA-256 更新校验渠道。

## 发布说明

- Release 工作流会在构建和测试通过后生成 `HAM.exe`、兼容资产和 `SHA256SUMS.txt`。
- 工作流会把本文件作为 GitHub Release 的中文更新说明，并在成功后刷新 `main/updates/latest.json`。
- 快速录入仍不连接 Excel；现场数据先保存到 SQLite，Excel 工作在后台处理。
