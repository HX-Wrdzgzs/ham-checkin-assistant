# HAM 点名助手 Native 1.0.3

本版本修复发布流水线的 UI 测试隔离问题，并重新生成 Windows 原生版发布包。

## 修复

- 修复 GitHub Actions 执行完整 Native 测试时没有启用 WPF UI 测试环境变量的问题。
- 发布流程现在会在隔离模式下运行 13 项 WPF UI 测试，避免启动真实数据初始化流程导致构建任务卡住或失败。
- 继续保留 1.0.2 中的 MIIT 资料同步文件锁修复、关于页/赞助入口和界面文案清理。

## 发布与更新

- 版本：`1.0.3`
- Windows x64 自包含单文件：`HAM.exe`
- 更新清单：`main/updates/latest.json`
- 下载文件发布后使用 SHA-256 校验；原有 GitHub Release 更新地址不变。
