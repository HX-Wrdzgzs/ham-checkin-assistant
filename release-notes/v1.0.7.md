# HAM 点名助手 Native 1.0.7

## 本版重点

- 新增中文省份与城市拼音混合写法，例如 `山东qd`、`安徽mas`、`湖南cs`，并用同一省份行政记录校验，避免误猜。
- 从实际点名数据补充 `jscz`、`jsha`、`jsxz`、`jssq`、`szzjg`、`shbs` 等跨省/跨城市简称回归。
- 修复 `南京师范大学仙林校区` 被城市前缀规则错误截断的问题，完整地点优先解析。
- 保留快捷小窗输入修复、提交修订号保护、后台启动检查更新和轻量过渡动画。

## 验证边界

- .NET 10.0.401 Release 构建、Native 核心测试、WPF UI 测试和视频案例回放均重新执行。
- Microsoft Pinyin 实体输入法、Microsoft Excel 桌面程序实际打开、GitHub Release 上传及远程资料下载仍需现场/发布环境验证。
