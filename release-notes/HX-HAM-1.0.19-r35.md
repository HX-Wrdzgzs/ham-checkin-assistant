# HAM 点名助手 Native 1.0.19-r35 演示候选版

这是面向今晚实机演示的 Windows 原生候选版，主要修复快速小窗在窄高尺寸下内容被底部区域遮挡的问题，并补齐截图中使用的 `1907` 设备简称。

## 本次更新

- 修复快速小窗在 `420×190` 最小尺寸下解析卡片向下溢出的问题。
- 解析区域改为独立滚动区域，输入框、提交按钮和底部状态栏不再被解析内容覆盖。
- 五个解析字段改为固定五列布局，窄窗口不再因为卡片换行把下方内容顶出窗口。
- 最近记录在小窗高度不足时自动收起，窗口恢复高度后自动显示。
- `1907` 自动补全为 `YAESU FT-1907R`，与 `4.2M`、`NJQX`、`25W` 组合时可完整识别。
- 增加最小尺寸边界测试和 `1907` 识别金标准测试。
- 效果图生成器新增真实 WPF `420×190` 最小小窗截图，并使用 `BA4RLL 1907 NJQX 4.2M 25W` 演示输入展示识别结果。
- 保持 MP4 软件窗口录制、麦克风选择、SQLite 热路径和 Excel 后台导出设计不变。
- 保持现有 GitHub Release、`main/updates/latest.json` 和 SHA-256 更新渠道不变。

## 已验证

- `1907` 识别金标准：11/11 通过。
- Native 核心测试基线：194/194 通过；本次新增金标准单独 11/11 通过。
- 快速小窗最小尺寸边界测试：1/1 通过。
- 其余 WPF UI 测试：32/32 通过。
- 自包含单文件 EXE：可启动、可等待输入、隔离数据目录可创建 SQLite。

## 已知限制

- 录屏“覆盖窗口颜色采样”测试在当前桌面会话中仍返回空颜色样本，尚未把这项环境敏感测试标为完整通过。
- 本候选版不代表正式稳定 Release；真实 Microsoft Excel 打开、微软拼音现场输入和长时间录屏仍需现场验收。

## 演示重点

1. 打开快速小窗并缩小到接近 `420×190`。
2. 输入 `BA4RLL 1907 NJQX 4.2M 25W`。
3. 确认解析结果显示 `YAESU FT-1907R`、南京栖霞区、`4.2米玻璃钢` 和 `25W`。
4. 确认解析区只在中间区域滚动，底部状态栏和“打开主窗口”仍可操作。
5. 恢复窗口高度，确认最近记录重新出现。
