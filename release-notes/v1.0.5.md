# HAM 点名助手 Native 1.0.5

本版本修复 GitHub Release 发布完成后更新清单同步失败的问题，并重新验证完整发布链路。

## 修复

- 修复工作流在同步 `main/updates/latest.json` 和兼容分支时，因 tag 工作区已有清单而无法 checkout 的问题。
- 通过精确的强制 checkout 切换到远端目标分支，再写入生成的真实 SHA-256 清单。
- 保留托管 CI 对真实桌面/媒体设备测试的精确过滤；本地 Windows 仍执行完整录屏和麦克风测试。

## 发布与更新

- 版本：`1.0.5`
- Windows x64 自包含单文件：`HAM.exe`
- 更新清单：`main/updates/latest.json`
